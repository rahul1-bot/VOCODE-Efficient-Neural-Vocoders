# APNet2 — baseline_cpu — Seed 43

This execution evaluates APNet2 with the `baseline_cpu` configuration on all 525 adaptive-benchmark LJSpeech utterances using evaluation seed 43. It measured PESQ 2.580162 and real-time factor 0.017281 on the registered CPU lane. The 520 batch-one timing observations had p50 115.631 ms and p95 158.161 ms. Peak host-process resident memory was 9818.3 MiB.

`config.yaml` defines the executed data, intervention, and timing conditions. `execution.log` records the run events, and `metrics.csv` contains the complete Study 2 measurement row.
