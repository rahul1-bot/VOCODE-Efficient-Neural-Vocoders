# HiFi-GAN V3 — baseline_cpu — Seed 43

This execution evaluates HiFi-GAN V3 with the `baseline_cpu` configuration on all 525 adaptive-benchmark LJSpeech utterances using evaluation seed 43. Peak host-process resident memory was 12989.7 MiB.
