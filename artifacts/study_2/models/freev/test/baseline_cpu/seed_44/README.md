# FreeV — baseline_cpu — Seed 44

This execution evaluates FreeV with the `baseline_cpu` configuration on all 525 adaptive-benchmark LJSpeech utterances using evaluation seed 44. It measured PESQ 3.379689 and real-time factor 0.008946 on the registered CPU lane. The 520 batch-one timing observations had p50 59.366 ms and p95 78.093 ms. Peak host-process resident memory was 9747.4 MiB.
