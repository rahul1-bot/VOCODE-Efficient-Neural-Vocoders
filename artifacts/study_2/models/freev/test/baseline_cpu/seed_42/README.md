# FreeV — baseline_cpu — Seed 42

This execution evaluates FreeV with the `baseline_cpu` configuration on all 525 adaptive-benchmark LJSpeech utterances using evaluation seed 42. It measured PESQ 3.379689 and real-time factor 0.009264 on the registered CPU lane. The 520 batch-one timing observations had p50 61.476 ms and p95 81.000 ms. Peak host-process resident memory was 9814.2 MiB.

`config.yaml` defines the executed data, intervention, and timing conditions. `execution.log` records the run events, and `metrics.csv` contains the complete Study 2 measurement row.
