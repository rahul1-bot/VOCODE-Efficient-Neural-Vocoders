# MelGAN — baseline_b200 — Seed 43

This execution evaluates MelGAN with the `baseline_b200` configuration on all 525 adaptive-benchmark LJSpeech utterances using evaluation seed 43. Peak host-process resident memory was 7175.2 MiB.
