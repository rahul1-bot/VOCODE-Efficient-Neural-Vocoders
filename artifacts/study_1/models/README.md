# Study 1 Models

Each executed-model directory contains the evidence for one member of the twelve-model Study 1 cohort. Experimental logs, resolved configurations, selected-state records, seed-specific evaluations, measurements, figures, and interpretations are organized by model. The stable `test/` path denotes the 525-utterance adaptive evaluation partition; its scores informed some budget gates and an inference correction, so the path does not imply untouched final-test independence. `hiftnet/` is an explicit exclusion record and is not counted as an executed result.
